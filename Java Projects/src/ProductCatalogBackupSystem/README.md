# Product Catalog Backup System

## Java Learning Journey

### Stage: File Handling

This project is part of my Java Learning Journey and demonstrates how to save and retrieve data using text files.

## Concepts Demonstrated

- HashMap
- File Handling
- Scanner
- Loops
- Exception Handling
- Collections Framework

## Project Description

This application allows users to:

1. Enter product IDs.
2. Enter product names.
3. Store products in a HashMap.
4. Save products to a text file.
5. Read the saved data from the file.
6. Display the stored products.

## How the Program Works

Example Input:

101
Laptop

102
Phone

103
Keyboard

The program creates a file named:

products.txt

and stores the data in the following format:

101,Laptop
102,Phone
103,Keyboard

After saving the data, the program reads the file and displays the contents on the screen.
